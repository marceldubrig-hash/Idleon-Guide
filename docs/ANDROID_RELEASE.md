Installierbare Android-Vorschau von Idleon Atlas. Lade **Idleon-Atlas-Android.apk** unter Assets herunter und öffne die Datei auf deinem Handy.

- Android 8 oder neuer; keine Browser- oder GitHub-Pages-Einrichtung nötig.
- Gesamte importierte Datenbank und Spielgrafiken in der APK enthalten; ohne Internetverbindung nutzbar.
- Vorhandene Atlas-Oberfläche in einer Android-WebView, mit Android-Zurücknavigation, Bildschirmrändern und Dateiauswahl für Backups.
- Externe Quellenlinks öffnen deinen Browser. Die App selbst fordert keine Internet- oder allgemeinen Speicherberechtigungen.
- Keine vollständig native Compose-Oberfläche; die Inhalte und Forschungslücken entsprechen dem dokumentierten Atlas-Datenstand.

Dies ist eine mit einem Entwicklungsschlüssel signierte Vorschau, noch keine Play-Store-Version. Der Schlüssel wird für Folgebuilds gecacht. Falls dieser Cache verloren geht, kann vor einem Update ein Backup und eine Neuinstallation erforderlich sein. Eine dauerhaft gesicherte Produktionssignierung ist noch offen.

Der SHA-256-Prüfwert liegt als separate Datei bei. Build, Android Lint und Emulatorprüfungen müssen vor der Veröffentlichung erfolgreich sein.
